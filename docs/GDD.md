# 꿈냥 RPG 게임 디자인

## 한 줄

스물한 살 별하가 꿈속으로 떨어져, 말하는 고양이 모찌와 장난감 총으로 몽환 괴물을 정리하는 액션 RPG.

## 기둥

1. **핵앤슬래시 루프.** 마을에서 의뢰를 받고, 구역의 무리를 정리하고, 전리품으로 장비를 바꾸고, 다시 더 깊은 꿈으로 간다.
2. **둘의 성장.** 별하의 사격 스킬과 모찌의 도발·치유·할퀴기가 따로 자란다.
3. **총의 손맛.** 물총은 빠르고, 비누방울은 느리게 터지고, 다트는 관통한다. 같은 총도 희귀도와 능력치가 다르다.
4. **보는 맛.** 라벤더, 분홍, 하늘, 별, 사탕 수정. 쿼터뷰에 가까운 탑다운. 캐릭터는 치비 비율의 파스텔 애니 스프라이트.

## 조작과 카메라

가로 16:9. 데스크탑은 마우스가 총구를 끌고, 클릭을 유지하면 연사한다. 터치는 왼쪽 스틱과 오른쪽 공격 버튼이고, 공격 중에는 사거리 안의 가장 가까운 적을 조준한다. 대시는 약 0.26초 무적과 잔상을 남긴다. 카메라는 이동 방향과 조준 쪽으로 살짝 앞선다.

맞을 때의 연출: 강한 타격과 치명타에 짧은 히트스톱, 피해량에 비례한 화면 흔들림, 넉백, 흰 피격 플래시, 총구 플래시, 투사체 잔상, 치명타는 더 큰 금색 숫자, 사망 시 파티클, 희귀도 색 광기둥, 잠시 후 주인공에게 빨려 드는 획득.

## 세계

| 구역 | 역할 |
| --- | --- |
| 꿈의 초원 | 잠에서 깨는 곳. 모찌와 만나고 슬라임 한 마리를 배운다. |
| 꿈의 마을 | 허브. 루나, 포포, 키키, 우물, 게시판. 들어오면 체력이 찬다. |
| 몽환의 숲 | 슬라임과 포자 꿈벌레. |
| 버섯 골짜기 | 그림자 토끼, 수정 박쥐, 정예. |
| 별빛 제단 | 보스 나이트메어 블룸. 살아있는 동안 출구가 잠긴다. |

별문 아래로 걸어 들어가면 다음 구역이다. 방금 나온 문으로는 바로 되돌아가지 않는다.

## 전투

피해는 `src/sim/formulas.ts`의 `calcDamage`.

- 기본 피해 = (무기 공격력 + 공격력 × 0.65) × 배율
- 방어 적용 = 기본 피해 × 100 / (100 + 방어력 × 2)
- 치명타 시 치명타 피해 배율을 곱하고, 최소 1

적 행동:

- **솜사탕 슬라임.** 웅크렸다가 뛰어든다.
- **포자 꿈벌레.** 거리를 유지하고 예고 후 포자를 쏜다.
- **그림자 토끼.** 선을 긋고 돌진한다.
- **수정 박쥐.** 발밑에 원을 그린 뒤 급강하한다.
- **정예.** 질긴 / 재빠른 / 불안정한 / 흡혈의. 더 크고, 색 오라가 있다. 불안정한 정예는 쓰러진 뒤 원이 터진다.
- **나이트메어 블룸.** 꽃잎 탄막, 바닥 원, 체력 절반 이하에서 돌진과 소환. 도발은 작은 괴물에게만 통한다.

물총은 짧은 연사, 비누방울은 맞거나 수명이 끝나면 범위 피해, 다트는 관통 3.

## 성장

레벨이 오르면 체력·공격·방어·이동이 오르고 별하 스킬 포인트 1. 짝수 레벨에는 모찌 포인트도 1. 시작 시 물보라 난사와 냥냥 도발은 배운 상태이고, 포인트가 1씩 있어 바로 다음 기술을 고를 수 있다.

스킬:

- 별하: 물보라 난사 → 비누 방벽 / 집중 사격 → 꿈의 감각(치명타 +5%)
- 모찌: 냥냥 도발 → 골골 치유 / 냥냥 펀치 → 행운의 방울(행운 +12)

쓰러지면 골드의 10%를 잃고, 첫 의뢰 전이면 초원, 이후에는 마을에서 체력이 찬 채로 눈을 뜬다.

## 장비와 상점

칸: 무기, 모자, 옷, 장신구, 모찌 목걸이.  
희귀도: 일반, 고급, 희귀, 영웅, 전설. 높은 등급일수록 능력치 개수와 배율이 는다. 행운은 높은 등급 확률을 민다.

포포에게서 포션과 장비를 사고, 가방의 장비를 판다. 키키는 장착 중인 총의 능력치를 골드로 다시 굴린다. 일반 등급은 굴릴 능력이 없다. 가방은 장착 중이지 않은 장비 24칸. 꿈가루와 장난감 부품, 포션은 따로 센다.

우물은 체력을 채우고 저장한다. 구역을 옮기거나 전투 보상이 생길 때도 저장한다.

## 이야기

1. **별빛 아래의 고양이.** 모찌와 대화하고, 초원 슬라임을 잡고, 마을에 도착하면 자동 완료.
2. **반짝이는 꿈가루.** 루나. 숲 괴물 8, 꿈가루 5. 돌아가 보고하면 희귀 베레모.
3. **꽃망울의 악몽.** 나이트메어 블룸 처치. 영웅 부적과 별하 포인트.
4. **장난감 공방의 부탁.** 키키. 부품 3개를 가져가면 희귀 꿈다트 총. 부품은 소모된다.

꿈가루와 부품은 의뢰를 받기 전에 주워 둔 것도 인정된다.

## 콘텐츠를 더하는 법

- **아이템.** `src/data/items.ts`에 정의하고, 상점에 넣을 거면 `SHOP`에 한 줄.
- **적.** 마을 구역의 적 모델과 행동은 `src/combat/foes.ts`·`src/combat/combat.ts`, 미궁의 무리는 `src/world/dungeon/horde.ts`·`waves.ts`.
- **스킬.** `src/data/skills.ts`. 액티브면 `HOTBAR`와 `WorldScene.cast`에 효과를 연결.
- **퀘스트.** `src/data/quests.ts`에 목표와 보상. 대사는 `src/data/dialogues.ts`의 `resolveDialogue`.
- **구역.** `src/data/zones.ts`에 크기, 소품, 적, 출구, 시작 지점. 출구 좌표는 별문 발밑을 넉넉히 덮고, 시작 지점은 그 사각형 밖에 둔다.
- **그림.** `tools/process_art.py`가 초록 배경을 지우고 `public/assets`로 넣는다. 초상화 키는 대사의 `portrait` 이름과 같아야 한다.
- **소리.** `tools/make_audio.py`가 `public/assets/audio`를 만든다.

규칙은 `src/sim`에만 두고 DOM·three.js를 부르지 않는다. 테스트는 `tests/systems.test.ts`.

## 이번 슬라이스에서 일부러 뺀 것

- 걷기·공격의 여분 프레임 애니메이션. 지금은 한 장의 스프라이트에 스쿼시, 총 반동, 잔상으로 움직임을 만든다.
- 모자·옷의 외형 변경. 스탯과 UI 아이콘만 바뀐다. 총 스프라이트만 장착에 따라 바뀐다.
- 여러 챕터, 도감, 업적, 협동.
